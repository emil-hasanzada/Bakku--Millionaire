# Bakkuş Millionaire

**Neçə ilə bir milyon?** — мемный калькулятор, который честно (и с иронией) отвечает, сколько лет тебе копить на первый миллион.

Один HTML-файл, без зависимостей и сборки. Открывается двойным кликом.

## Что считает

- `накопления = зарплата − расходы` в месяц
- срок до 1 000 000 ₼ в **годах и месяцах**
- сколько откладывать в неделю
- сколько iPhone в одном миллионе
- какую долю дохода ты вообще откладываешь

Если расходы выше дохода — честно показывает «Heç vaxt».

## Особенности

- **Mobile-first**: safe-area, тач-таргеты от 50px, системная тёмная тема
- **Apple-like UI** без единого неона: grouped lists, hairline-разделители, SF-шрифты
- Азербайджанский интерфейс, валюта ₼ (манат)
- Прелоадер при расчёте

## Запуск

```bash
open index.html
```

Или поднять локально:

```bash
python3 -m http.server 8000
```
